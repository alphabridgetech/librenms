Template Push Configuration

Template Builder
How to build a template:
  1. Give your template a name above.
  2. Click Add Field for each value you want to collect.
  3. Field Types:
    • Text/Number — user types a value, use {{value}} in the command
    • Dropdown — user picks from options, format: val:cmd, val2:cmd2
    • Checkbox — if checked, command is pushed as-is
    • Put Only Cmd — no user input, command is always pushed
    • Dynamic Rules List — repeater with custom variables, e.g. {{from}} {{to}}
  4. Cross-Field References: Use {{field:Label}} in any command to pull another field's value.
    Example: switchport pvid {{field:VLAN ID}}
  5. Click Save Template to store it, then load it on the right side.
